# Logo 候选说明

本目录包含 3 个 logo 设计候选。
选择后，主 logo 应放在 `../logo.svg`，并被 README 顶部引用。

---

## 候选 A · `A-pocket.svg` · 口袋 + 错位卡片（推荐）

| 项 | 内容 |
|----|------|
| 形状 | 倒梯形口袋 + 3 张错位堆叠卡片 |
| 颜色 | `#0F172A` (深) + `#F59E0B` (琥珀 1 张) + 白 (2 张) |
| 隐喻 | "Pocket" + "对话堆叠" |

**适合做主推荐** —— 直接表达两层隐喻，不依赖文字也能读懂。
**注意**：在 16×16 favicon 下卡片可能糊，建议加单色简化版备用。

ASCII 预览：
```
    ╔═══════════════╗
    ║               ║
    ║  ▬▬▬▬▬▬▬      ║
    ║   ▬▬▬▬▬▬▬▬    ║
    ║  ▬▬▬▬▬▬       ║
    ║               ║
    ╚═══════╲═══════╝
              ╲
```

## 候选 B · `B-bubble.svg` · 双气泡折叠

| 项 | 内容 |
|----|------|
| 形状 | 前后两个对话气泡错位重叠 |
| 颜色 | `#0F172A` (描边 + 实心) + 白 |
| 隐喻 | "对话 → 沉淀成副本" |

**优势**：favicon 友好，小尺寸下仍清晰。
**劣势**：和"上下文持久化"的关联偏弱。

ASCII 预览：
```
   ╭───────────╮
   │           │   ← 后置气泡（描边，副本）
   ╰───────────╯
       ╭───────────╮
       │  ▬▬ ▬▬ │  ← 前置气泡（实心，当前对话）
       ╰─────┬─╯
             │
```

## 候选 C · `C-pocket-letter.svg` · 字母 C + 内部气泡

| 项 | 内容 |
|----|------|
| 形状 | 粗壮字母 C + 内部对话气泡 |
| 颜色 | `#0F172A` (字母) + `#F59E0B` (气泡) |
| 隐喻 | "C for Context" + 气泡被"装进口袋" |

**优势**：文字 logo 形式，与品牌名 "ContextPocket" 呼应。
**劣势**：首字母"C"的关联稍弱（也可以理解成 "Chat" 或 "Carry"）。

ASCII 预览：
```
   ╭─────╮
  │       ╲
  │  ┌──┐  │
  │  │██│  │   ← 字母 C 包着一个小气泡
  │  └──┘  │
  │       ╱
   ╰─────╯
```

## 共同设计原则

- ✅ 单深色为主，1 个克制暖色点缀
- ✅ 无渐变、无光晕、无霓虹
- ✅ 几何形状 + 圆角
- ✅ 64×64 viewBox，任意尺寸可缩放
- ❌ 不含对称花纹
- ❌ 不含 emoji 风元素

---

## 选定后的步骤

1. 选定其中一个 SVG，复制到 `../logo.svg`
2. 在 README.md / README.zh-CN.md 顶部加上 logo 引用
3. 删除本目录其他候选（或保留作设计历史）
4. （可选）做 16×16 / 32×32 favicon 简化版
